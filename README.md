# СимургФарм — кейс хакатона ШЕН

Решение кейса **СимургФарм** в рамках хакатона **ШЕН** (20–22 ноября 2026).

Задача: по характеристикам пациента предсказать фармакокинетические параметры условного препарата *экзампломицин* — клиренс (`CL_L_h`) и объём распределения (`Vd_L`) — и на их основе рассчитать конкурсную дозу, удовлетворяющую заданным ограничениям.

> **Важно:** экзампломицин — учебный препарат. Модели и рассчитанные дозы предназначены **только для конкурсного кейса**, не для медицинского применения.

---

## Данные

| Файл | Строк | Описание |
|------|------:|----------|
| `expamlomycin_train.csv` | 2000 | Признаки пациента + таргеты `CL_L_h`, `Vd_L` |
| `expamlomycin_test.csv` | 500 | Только признаки (разделитель `;`) |

**Признаки:** возраст, пол, раса, рост, вес, безжировая масса (`lean_bw_kg`), креатинин, альбумин, CRP, сепсис, генетический вариант OAT, глюкоза, лактат, AST.

**Таргеты:** `CL_L_h`, `Vd_L` → из них вычисляется `Dose_mg` по условиям задания.

## Подход

### 1. EDA и биологические гипотезы
- Проверка пропусков, сдвига Train/Test, корреляций.
- Формулы из литературы: **Cockcroft–Gault**, **CKD-EPI 2021**, **Watson TBW**, **Janmahasatian LBW**, adjusted body weight.
- Наблюдение: `lean_bw_kg` **точно** совпадает с формулой Janmahasatian (2500/2500 после округления) — признак вычисляемый, а не независимый.

### 2. Моделирование CL и Vd
- **CL:** связь с оценкой клиренса креатинина (Cockcroft–Gault) и генетическим вариантом OAT; при отсутствии креатинина — отдельная модель восстановления.
- **Vd:** вес, сепсис и их взаимодействие; альбумин даёт небольшой дополнительный вклад.
- Ансамбль (CatBoost + параметрические модели), OOF-калибровка, честная 5-fold CV без использования тестовых ответов.

### 3. Расчёт дозы
Доза выбирается внутри допустимого интервала, заданного предсказанными `CL` и `Vd` (ограничения из PDF задания). Калибровка опирается на эмпирическое распределение ошибок на OOF-предсказаниях обучающей выборки.

### 4. Метрики
Конкурсные: **MAPE** по `CL`/`Vd` и доля доз в допустимом диапазоне (**TAR**). Финальный score по правилам площадки.

## Как воспроизвести

1. Открыть нужный ноутбук в Colab (или Jupyter).
2. Загрузить `expamlomycin_train.csv` и `expamlomycin_test.csv` в рабочую папку.

   - `submission.csv` — формат для отправки;

Минимальные зависимости: `numpy`, `pandas`, `scikit-learn`, `scipy`, `statsmodels`, `catboost`, `matplotlib`, `seaborn`, `joblib`.

## Результаты исследования (кратко)

| Наблюдение | Вывод для модели |
|------------|------------------|
| Janmahasatian LBW ≡ `lean_bw_kg` | Не независимый признак; можно не дублировать |
| CG (фактический вес) + OAT | Лучшая из проверенных простых формул для CL на этих данных |
| Вес × сепсис | Основной драйвер Vd |
| Альбумин | Небольшой, но полезный вклад в Vd |
| Watson / BMI / CKD-EPI | Биологически осмысленны, прироста MAPE в эксперименте не дали |
| Пропуски креатинина | Отдельная ветка / fallback-модель обязательна |

Подробности — в ноутбуках с таблицами CV и bootstrap-интервалами.

## Ограничения

- Результаты кросс-валидации **не гарантируют** качество на скрытом тесте.
- Формулы CG/CKD-EPI в реанимации при нестабильной функции почек ограничены; здесь они используются только как признаки конкурса.
- Генетический эффект OAT наблюдается **в данных кейса**; перенос на реальный аминогликозид не обоснован.
- Никаких утечек: `patient_id` и истинные `CL`/`Vd` не входят в входные признаки моделей.
